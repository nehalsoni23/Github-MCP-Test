# Todo App

A simple and elegant Todo application built with modern HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Persistent storage using localStorage
- Clean and responsive design
- Mobile-friendly interface
- Accessibility support
- Smooth animations
- Error handling

## How to Use

1. Open the app in your web browser
2. Type your task in the input field
3. Click "Add Task" or press Enter to add the task
4. Click on a task to mark it as completed
5. Click the Delete button to remove a task
6. Tasks persist between browser sessions

## Project Structure

- `index.html` - Semantic HTML structure with accessibility features
- `styles.css` - Modern CSS with variables and responsive design
- `script.js` - Object-oriented JavaScript with error handling

## Technical Features

- CSS Custom Properties (variables) for consistent theming
- Mobile-first responsive design
- Semantic HTML5 elements
- ARIA labels for accessibility
- Class-based JavaScript architecture
- Error handling for localStorage operations
- Smooth transitions and hover effects
- System font stack for optimal performance

## Technologies Used

- HTML5 with semantic elements
- Modern CSS3 with custom properties
- JavaScript (ES6+) with OOP principles
- localStorage for data persistence
- Responsive design principles
