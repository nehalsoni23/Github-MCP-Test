# Todo App

A simple and elegant Todo application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Persistent storage using localStorage
- Clean and responsive design

## How to Use

1. Open `index.html` in your web browser
2. Type your task in the input field
3. Click "Add Task" or press Enter to add the task
4. Click on a task to mark it as completed
5. Click the Delete button to remove a task

## Project Structure

- `index.html` - The main HTML file
- `styles.css` - Contains all the styling
- `script.js` - Contains the application logic

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- localStorage for data persistence
